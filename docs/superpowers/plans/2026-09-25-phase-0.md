# Omnia Character Cognition Phase 0 Implementation Plan

> **For agentic workers:** Implement each task with a failing test, verify it, then add the smallest implementation. This plan is executed in the current task; no separate task is required.

**Goal:** Build a small independent JS-Slash-Runner cognition experiment with mock mode and a localhost Jev bridge, then prepare controlled A/B evaluation.

**Architecture:** A browser-side script reads the active character, recent chat and bounded worldbook candidates, asks a provider for a private snapshot, and injects it once into ST's normal generation. A separate loopback Node process owns the Jev credential and reuses Omnia's evaluation client. Stale async results and provider errors leave normal generation unchanged.

**Tech Stack:** TypeScript, esbuild, Vitest, Zod, Node 22, existing Omnia Jev package.

**Spec:** User attachment “Omnia Character Cognition for SillyTavern — Phase 0 Experimental Plugin / JS-Slash-Runner Prototype”.

## Global Constraints

- Separate `omnia-cognition-st` repository; no SillyTavern core or Omnia Engine edits.
- No key in browser code, cards, worldbooks, variables, logs or prompts.
- Modes OFF, RELEVANCE, COGNITION, DEBUG; no production claims before actual ST installation and paired trials.
- Group chat disabled until generating character can be identified reliably.
